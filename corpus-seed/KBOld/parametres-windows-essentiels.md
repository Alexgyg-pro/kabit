# Paramètres Windows essentiels — réglages courants

## Accès rapide aux paramètres

| Raccourci         | Destination                        |
|-------------------|------------------------------------|
| Win + I           | Paramètres Windows                 |
| Win + X           | Menu Expert (Gestionnaire de tâches, Explorateur, etc.) |
| Win + Pause        | Informations système               |
| Win + R           | Boîte Exécuter                     |

## Affichage et résolution

```
Paramètres > Système > Affichage
```
- **Résolution recommandée** : toujours sélectionner la résolution marquée (recommandé)
- **Mise à l'échelle** : 100% pour les écrans FHD, 125-150% pour les écrans QHD/4K
- **Disposition des écrans multiples** : faire glisser les moniteurs pour correspondre à leur position physique

## Gestion de l'alimentation

```
Panneau de configuration > Options d'alimentation
```
- **Mode recommandé FinCorp** : Équilibré
- **Mode haute performance** : uniquement pour les postes fixes ou branchés en permanence
- Désactiver la mise en veille automatique si gênante pour certains utilisateurs :
  ```
  Paramètres > Système > Alimentation et mise en veille > Mettre en veille : Jamais
  ```

## Langue et clavier

```
Paramètres > Heure et langue > Langue et région
```
- Langue d'affichage Windows : Français (France)
- Supprimer toutes les langues sauf `Français (France)` pour éviter les bascules accidentelles
- Format de date : JJ/MM/AAAA (vérifier dans Région > Formats supplémentaires)

## Notifications et mode Focus

```
Paramètres > Système > Notifications
```
Désactiver les notifications des applications non essentielles.
En réunion : **Win + A** > Mode Focus pour bloquer toutes les notifications.

## Explorateur de fichiers

```
Explorateur > Affichage > Options > Modifier les options des dossiers et de recherche
```
Réglages utiles :
- Afficher les extensions de fichiers (onglet Affichage > décocher "Masquer les extensions...")
- Afficher les fichiers cachés (onglet Affichage > cocher "Afficher les fichiers, dossiers et lecteurs cachés")

## Mise à jour Windows — vérification manuelle

```
Paramètres > Windows Update > Rechercher des mises à jour
```
En cas de mise à jour urgente hors calendrier Intune : contacter la Boutique IT avant de lancer manuellement.

## Applications par défaut

```
Paramètres > Applications > Applications par défaut
```
Définir Chrome ou Edge comme navigateur par défaut, Outlook comme client mail.
