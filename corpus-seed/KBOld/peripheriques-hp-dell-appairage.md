# Consoles d'appairage HP / Dell — mode d'emploi

## Le problème

Les souris et claviers sans fil HP et Dell fournis au parc perdent parfois leur appairage avec le récepteur USB : changement de pile, redémarrage du récepteur, ou dongle débranché par erreur. Chez FinCorp Solutions, le ré-appairage passe par la console constructeur dédiée, disponible au catalogue logiciel standard :

- **HP** : HP Easy Connect
- **Dell** : Dell Peripheral Manager

## HP Easy Connect

1. Lancer **HP Easy Connect** depuis le menu Démarrer (déjà installé sur tous les postes du parc HP)
2. Vérifier que le récepteur USB est bien branché
3. Cliquer sur **Ajouter un périphérique**
4. Mettre la souris ou le clavier en mode appairage : maintenir le bouton de connexion situé sous l'appareil pendant 3 secondes, jusqu'au clignotement du voyant
5. Sélectionner le périphérique détecté dans la liste, puis **Associer**

## Dell Peripheral Manager

1. Lancer **Dell Peripheral Manager** depuis le menu Démarrer
2. Onglet **Périphériques** > bouton **Ajouter un périphérique**
3. Basculer l'interrupteur sous l'appareil sur la position appairage (ou maintenir le bouton dédié selon le modèle)
4. Confirmer l'appairage une fois le périphérique détecté dans la liste

## Si le récepteur n'est pas détecté

- Essayer un autre port USB (éviter les hubs non alimentés)
- Vérifier dans le Gestionnaire de périphériques que le récepteur n'est pas en erreur (point d'exclamation jaune) — si besoin, désinstaller puis rebrancher pour réinstallation automatique du pilote
- En dernier recours, remplacer le récepteur par un exemplaire neuf pris en stock Boutique
