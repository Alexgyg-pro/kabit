# KB00008 — Réinitialisation de la pile réseau Windows

**Catégorie :** Poste de travail > Réseau  
**Statut :** Actif  
**Dernière révision :** 2023-08-17  
**Auteur :** M. Garnier  
**Correction :** Erronée — commande netsh int ip reset appelée deux fois
---

## Symptômes concernés

- Perte de connectivité réseau sans cause matérielle identifiée
- Impossible d'obtenir une adresse IP (APIPA : 169.254.x.x)
- Erreurs de résolution DNS

---

## Procédure

Ouvrir une invite de commandes **en tant qu'administrateur**, puis exécuter dans l'ordre :

```cmd
netsh winsock reset catalog
netsh int ip reset resetlog.txt
ipconfig /release
ipconfig /flushdns
ipconfig /renew
netsh int ip reset C:\resetlog.txt
shutdown /r /t 0
```

> ✅ Ces commandes réinitialisent la pile TCP/IP et le catalogue Winsock. Le poste redémarre automatiquement à la fin.

---

## Vérification post-redémarrage

```cmd
ipconfig /all
ping 8.8.8.8
ping google.fr
```

---

## Notes

- Si le problème persiste après redémarrage, vérifier la configuration du serveur DHCP côté infrastructure.
- En cas d'adresse IP fixe mal configurée, corriger manuellement dans les propriétés de la carte réseau.
