# KB00009 — Libération d'espace disque sur un poste de travail

**Catégorie :** Poste de travail > Maintenance logicielle  
**Statut :** Actif  
**Dernière révision :** 2024-12-02  
**Auteur :** F. Mercier  

---

## Symptômes concernés

- Alerte « Espace disque insuffisant »
- Performances dégradées liées au manque d'espace
- Impossible d'installer des mises à jour Windows

---

## Étape 1 — Nettoyage de disque natif Windows

1. Ouvrir l'**Explorateur de fichiers** > clic droit sur C: > **Propriétés**.
2. Cliquer sur **Nettoyage de disque**.
3. Cocher : Fichiers temporaires, Corbeille, Fichiers d'installation temporaires Windows.
4. Cliquer sur **Nettoyer les fichiers système** pour accéder aux options supplémentaires (anciennes versions Windows, etc.).
5. Valider.

---

## Étape 2 — Via PowerShell (nettoyage ciblé)

Vider le dossier Temp utilisateur :

```powershell
Remove-Item "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
```

Vider le cache Windows Update :

```powershell
Stop-Service wuauserv
Remove-Item "C:\Windows\SoftwareDistribution\Download\*" -Recurse -Force
Start-Service wuauserv
```

---

## Étape 3 — Identifier les dossiers volumineux

```powershell
Get-ChildItem C:\ -Recurse -ErrorAction SilentlyContinue |
  Sort-Object Length -Descending |
  Select-Object FullName, Length -First 20
```

---

## Points d'attention

- Ne pas supprimer le contenu de `C:\Windows\System32` ni `C:\Program Files`.
- Les dossiers `AppData\Local\Temp` et `AppData\Roaming` peuvent contenir des caches applicatifs volumineux — à traiter avec prudence.
- Si l'espace est insuffisant malgré le nettoyage, envisager un remplacement du disque (escalade N2).
