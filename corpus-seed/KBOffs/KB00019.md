# KB00019 — Reconstruction d'un profil utilisateur Windows corrompu

**Catégorie :** Comptes utilisateurs > Profil Windows  
**Statut :** Actif  
**Dernière révision :** 2024-06-18  
**Auteur :** T. Blanchard  
**Correction :** Correcte
---

## Symptômes concernés

- L'utilisateur se connecte avec un « profil temporaire »
- Le bureau est vide, les paramètres personnalisés sont perdus
- Message à la connexion : « Nous n'avons pas pu vous connecter à votre compte »
- Le profil se charge très lentement ou génère des erreurs

---

## Diagnostic préalable

```powershell
# Vérifier les profils présents sur le poste
Get-WmiObject -Class Win32_UserProfile | Select-Object LocalPath, SID, Special
```

Identifier le profil corrompu (généralement présent avec `.bak` ou doublon).

---

## Procédure — Renommage du profil corrompu

1. Se connecter en tant qu'administrateur local.
2. Ouvrir **Regedit** : `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList`.
3. Repérer la clé correspondant au SID de l'utilisateur (deux clés peuvent exister si profil corrompu — l'une avec `.bak`).
4. Renommer la clé `.bak` en supprimant l'extension `.bak`, et renommer l'autre en ajoutant `.old`.
5. Dans la clé conservée, vérifier que `ProfileImagePath` pointe vers le bon chemin (`C:\Users\jdupont`).
6. Redémarrer le poste.
7. Se reconnecter avec le compte de l'utilisateur.

---

## Si le profil est irrécupérable

1. Sauvegarder les données utilisateur (`C:\Users\jdupont\Documents`, `Desktop`, etc.) si accessibles.
2. Supprimer le profil via **Propriétés système** > **Paramètres système avancés** > **Profils des utilisateurs** > **Paramètres**.
3. Laisser Windows recréer un profil propre à la prochaine connexion.
4. Restaurer les données sauvegardées.

---

## Notes

- Ne jamais supprimer manuellement le dossier `C:\Users\nomutilisateur` sans avoir supprimé la clé de registre correspondante au préalable.
- Si le profil est itinérant (Roaming Profile), contacter le N2.
