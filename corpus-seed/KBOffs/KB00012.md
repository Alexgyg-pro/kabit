# KB00012 — Compte Active Directory expiré

**Catégorie :** Comptes utilisateurs > Active Directory  
**Statut :** Actif  
**Dernière révision :** 2024-07-22  
**Auteur :** S. Legrand  
**Correction :** Correcte
---

## Symptômes concernés

- Message à la connexion : « Votre compte a expiré. Veuillez contacter votre administrateur »
- L'utilisateur ne peut pas se connecter malgré un mot de passe correct
- Compte visible dans ADUC mais inactif

---

## Contexte

Les comptes AD peuvent avoir une date d'expiration définie (CDD, prestataires, comptes temporaires). L'expiration bloque la connexion sans verrouiller le compte au sens strict.

---

## Procédure — Vérification de la date d'expiration

```powershell
Get-ADUser -Identity "jdupont" -Properties AccountExpirationDate | Select-Object Name, AccountExpirationDate
```

---

## Procédure — Renouvellement via ADUC

1. Ouvrir **ADUC**, localiser le compte.
2. Clic droit > **Propriétés** > onglet **Compte**.
3. Section **La fin du compte** : modifier la date ou sélectionner **Jamais**.
4. Valider.

---

## Procédure — Via PowerShell

```powershell
# Supprimer la date d'expiration (compte permanent)
Set-ADAccountExpiration -Identity "jdupont" -DateTime "01/01/2099"

# Ou supprimer complètement la limite
Clear-ADAccountExpiration -Identity "jdupont"
```

---

## Points d'attention

- Vérifier avec le manager ou les RH que le renouvellement est autorisé (notamment pour les CDD et prestataires).
- Ne pas renouveler un compte sans validation hiérarchique pour les comptes temporaires.
- Tracer la décision dans le ticket.
