# Raccourcis clavier Windows — indispensables

## Raccourcis système essentiels

| Raccourci            | Action                                          |
|----------------------|-------------------------------------------------|
| Win + L              | Verrouiller la session                          |
| Win + D              | Afficher/masquer le bureau                      |
| Win + E              | Ouvrir l'Explorateur de fichiers                |
| Win + I              | Ouvrir les Paramètres                           |
| Win + R              | Ouvrir la boîte Exécuter                        |
| Win + X              | Menu Expert (accès rapide aux outils admin)     |
| Win + Pause          | Informations système                            |
| Win + Tab            | Vue des tâches (bureaux virtuels)               |
| Win + Ctrl + D       | Créer un nouveau bureau virtuel                 |
| Win + Ctrl + →/←     | Passer au bureau virtuel suivant/précédent      |
| Win + V              | Historique du presse-papiers                    |
| Win + .              | Insérer des émojis / symboles                   |
| Win + Shift + S      | Capture d'écran partielle (outil Capture)       |
| Ctrl + Shift + Échap | Gestionnaire des tâches directement             |
| Alt + F4             | Fermer l'application active                     |
| Alt + Tab            | Passer d'une application à l'autre              |

## Raccourcis de dépannage

| Raccourci                  | Usage support                                  |
|----------------------------|------------------------------------------------|
| Win + Ctrl + Shift + B     | Réinitialiser le pilote graphique              |
| Ctrl + Alt + Suppr         | Sécurité Windows (déconnexion, verrouillage)   |
| F5                         | Actualiser le bureau ou l'Explorateur          |
| Shift + Suppr              | Supprimer sans passer par la corbeille         |
| Win + P                    | Modes d'affichage (écrans multiples)           |
| Win + K                    | Connexion à un écran sans fil                  |
| Win + A                    | Centre de notifications                        |
| Win + N                    | Ouvrir le panneau des notifications (Win 11)  |

## Raccourcis dans l'Explorateur de fichiers

| Raccourci     | Action                                  |
|---------------|-----------------------------------------|
| Alt + ←       | Dossier précédent                       |
| Alt + →       | Dossier suivant                         |
| Alt + ↑       | Dossier parent                          |
| F2            | Renommer le fichier sélectionné         |
| F11           | Plein écran                             |
| Ctrl + Z      | Annuler la dernière action (déplacer, renommer) |

## Raccourcis Word/Excel utiles (rappel rapide)

| Raccourci       | Action                        |
|-----------------|-------------------------------|
| Ctrl + S        | Enregistrer                   |
| Ctrl + Z        | Annuler                       |
| Ctrl + Y        | Rétablir                      |
| Ctrl + F        | Rechercher                    |
| Ctrl + Home/End | Début/fin du document         |
| F12             | Enregistrer sous              |
| Alt + F4        | Fermer (propose de sauvegarder)|
