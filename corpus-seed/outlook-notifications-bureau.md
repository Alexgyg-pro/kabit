# Outlook — notifications de bureau absentes ou intempestives

## Symptômes
- Aucune alerte visuelle lors de la réception d'un email
- Son de notification absent
- Les notifications s'affichent mais disparaissent trop vite
- Notifications en dehors des heures de travail (trop intrusives)

## Étape 1 — Vérifier les paramètres Outlook

Fichier > Options > Messagerie > **Arrivée des messages**  
Cocher selon les besoins :
- ☑ Émettre un signal sonore
- ☑ Afficher une alerte sur le Bureau
- ☑ Modifier brièvement le pointeur de la souris
- ☑ Afficher une icône dans la barre des tâches

## Étape 2 — Vérifier les paramètres Windows

Paramètres Windows > Système > **Notifications et actions**  
- Vérifier que les notifications sont activées globalement
- Chercher "Microsoft Outlook" dans la liste > activer les notifications

## Étape 3 — Vérifier le mode "Ne pas déranger" de Windows

Windows 11 : cliquer sur l'heure en bas à droite > vérifier si le mode **Ne pas déranger** est actif (icône lune).  
Si actif : cliquer pour désactiver.

## Étape 4 — Problème de règles masquant les notifications

Si certains emails n'affichent jamais de notification : une règle Outlook déplace peut-être ces messages avant que la notification ne soit déclenchée.  
Fichier > Gérer les règles et alertes > passer en revue les règles actives.

## Étape 5 — Réduire les notifications intempestives

Pour ne recevoir des notifications que pour les emails importants :  
Créer une règle : Fichier > Gérer les règles > Nouvelle règle > "Afficher une alerte sur le bureau" uniquement pour les emails de certains expéditeurs ou marqués Haute importance.
