## Symptômes / Contexte
Écran bleu avec message d'erreur et redémarrage automatique.

## Procédure
1. Noter le code d'erreur affiché.
2. Désactiver le redémarrage automatique sur Windows 7 : Propriétés > Paramètres système avancés > Démarrage et récupération > décocher **Redémarrer automatiquement**.
3. Analyser les fichiers minidump avec **WinDbg**.
4. Vérifier les causes fréquentes : 
   - IRQL_NOT_LESS_OR_EQUAL : mettre à jour les pilotes.
   - MEMORY_MANAGEMENT : lancer Windows Memory Diagnostic.
   - BAD_POOL_HEADER : scanner antivirus et désinstaller les logiciels récemment installés.
   - NTFS_FILE_SYSTEM : exécuter **chkdsk C: /f /r** et redémarrer.

## Vérification
Vérifier que l'écran bleu ne se reproduit plus après les étapes ci-dessus.
