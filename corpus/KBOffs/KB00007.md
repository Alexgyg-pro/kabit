# KB00007 — Résolution des écrans bleus (BSOD)

**Catégorie :** Poste de travail > Diagnostic  
**Statut :** Actif  
**Dernière révision :** 2019-11-05  
**Auteur :** J. Petit  

---

## Symptômes concernés

- Écran bleu avec message d'erreur et redémarrage automatique
- Code d'erreur affiché (ex : IRQL_NOT_LESS_OR_EQUAL, PAGE_FAULT_IN_NONPAGED_AREA)

---

## Procédure

### Récupérer le code d'erreur

Sur Windows 7 : l'écran bleu affiche directement le code. Le noter.

Sur Windows 7, désactiver le redémarrage automatique pour avoir le temps de lire l'erreur :
- Poste de travail > Propriétés > Paramètres système avancés > Démarrage et récupération > décocher **Redémarrer automatiquement**.

### Analyser le fichier de vidage mémoire

Les fichiers minidump se trouvent dans `C:\Windows\Minidump`.
Utiliser **WinDbg** (Windows Debugger) pour les analyser — outil disponible sur le poste d'administration.

### Causes fréquentes et résolutions

| Code d'erreur | Cause probable | Action |
|---|---|---|
| IRQL_NOT_LESS_OR_EQUAL | Pilote défaillant | Voir KB sur mise à jour pilotes |
| MEMORY_MANAGEMENT | RAM défectueuse | Lancer Windows Memory Diagnostic |
| BAD_POOL_HEADER | Logiciel tiers ou virus | Scan antivirus + désinstallation récente |
| NTFS_FILE_SYSTEM | Disque dur défaillant | Chkdsk |

### Commande Chkdsk

```cmd
chkdsk C: /f /r
```
Redémarrer pour exécution au prochain démarrage.

---

## Notes

> ⚠️ Cette KB a été rédigée pour Windows 7. Certaines procédures peuvent différer sur Windows 10/11. Une mise à jour est nécessaire.
