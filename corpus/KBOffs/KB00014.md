# KB00014 — Réactivation d'un compte Active Directory désactivé

**Catégorie :** Comptes utilisateurs > Active Directory  
**Statut :** Actif  
**Dernière révision :** 2023-02-14  
**Auteur :** M. Garnier  

---

## Symptômes concernés

- Message à la connexion : « Ce compte d'utilisateur a été désactivé »
- Le compte est visible dans ADUC avec une icône grisée ou barrée
- L'utilisateur ne peut pas se connecter malgré un mot de passe valide

---

## Causes fréquentes

- Désactivation automatique après inactivité prolongée (politique de sécurité)
- Désactivation manuelle lors d'une absence longue durée
- Erreur de manipulation sur le compte

---

## Procédure — Via ADUC

1. Ouvrir **Active Directory Users and Computers**.
2. Localiser le compte (il peut être dans une OU spécifique aux comptes désactivés).
3. Clic droit > **Activer le compte**.
4. Si le compte a été déplacé dans une OU de désactivation, le replacer dans l'OU d'origine.

---

## Procédure — Via PowerShell

```powershell
Enable-ADAccount -Identity "jdupont"
```

---

## Vérification

```powershell
Get-ADUser -Identity "jdupont" -Properties Enabled, LockedOut, AccountExpirationDate | Select-Object Name, Enabled, LockedOut, AccountExpirationDate
```

---

## Points d'attention

- Vérifier systématiquement pourquoi le compte a été désactivé avant de le réactiver.
- Pour les départs RH, ne jamais réactiver sans validation explicite des RH ou de la DSI.
- Si le compte est à la fois désactivé et expiré, traiter les deux points (voir aussi KB00011 et KB00012).
