# KB00011 — Réinitialisation du mot de passe Active Directory

**Catégorie :** Comptes utilisateurs > Active Directory  
**Statut :** Actif  
**Dernière révision :** 2025-02-10  
**Auteur :** S. Legrand  

---

## Symptômes concernés

- L'utilisateur a oublié son mot de passe
- Le compte est verrouillé suite à trop de tentatives échouées
- Le mot de passe a expiré et l'utilisateur ne peut plus se connecter

---

## Prérequis

- Accès à la console **Active Directory Users and Computers (ADUC)** sur le poste d'administration
- Droits de réinitialisation de mot de passe sur l'OU concernée
- Vérification de l'identité de l'utilisateur effectuée (badge, appel superviseur, etc.)

---

## Procédure — Via ADUC

1. Ouvrir **Active Directory Users and Computers**.
2. Rechercher le compte utilisateur (Ctrl+F, saisir le login ou le nom).
3. Clic droit sur le compte > **Réinitialiser le mot de passe**.
4. Saisir un mot de passe temporaire respectant la politique de complexité.
5. Cocher **L'utilisateur doit changer de mot de passe à la prochaine ouverture de session**.
6. Valider.
7. Si le compte est verrouillé : clic droit > **Propriétés** > onglet **Compte** > décocher **Le compte est verrouillé**.

---

## Procédure — Via PowerShell

```powershell
# Réinitialiser le mot de passe
Set-ADAccountPassword -Identity "jdupont" -Reset -NewPassword (ConvertTo-SecureString "TempPass123!" -AsPlainText -Force)

# Forcer le changement au prochain login
Set-ADUser -Identity "jdupont" -ChangePasswordAtLogon $true

# Déverrouiller le compte si nécessaire
Unlock-ADAccount -Identity "jdupont"
```

---

## Politique de mot de passe en vigueur

- Longueur minimale : 12 caractères
- Doit contenir : majuscule, minuscule, chiffre, caractère spécial
- Historique : 10 derniers mots de passe mémorisés
- Durée de validité : 90 jours

---

## Notes

- Communiquer le mot de passe temporaire par téléphone uniquement, jamais par mail ou Teams.
- Tracer l'intervention dans le ticket associé.
